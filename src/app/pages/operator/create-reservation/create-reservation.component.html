Bloqueado por Backend

El equipo del operador no puede crear reservas a nombre de un cliente

El endpoint real (POST /api/tenants/{{ '{tenantId}' }}/reservations) exige una sesión JWT y toma siempre el identificador del cliente desde ese mismo token — no acepta un customerId distinto en el cuerpo de la solicitud. Por diseño del Backend, crear una reserva es una acción exclusiva del propio Cliente autenticado desde el Portal Cliente (Reservar tour).

Si el Backend llega a exponer en el futuro un endpoint para que Administrador/Colaborador registren una reserva a nombre de un cliente, esta pantalla se conectará a él. Por ahora no se simula ese flujo.
